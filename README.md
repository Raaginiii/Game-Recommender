# Game Recommendation System

A simple Streamlit app that recommends games using the trained machine learning model in `model.pkl`.

## What It Does

- Recommends similar games from a selected game name.
- Recommends games from selected genres, platforms, and tags.
- Runs locally with Streamlit only.

## Project Files

```text
.
├── app.py
├── model.pkl
├── model.ipynb
├── requirements.txt
├── docs/
└── ml/
```

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
